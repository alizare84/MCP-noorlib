# noorlib-mcp

سرور MCP برای **کتابخانه دیجیتال نور (noorlib.ir)** — جستجو، فهرست مطالب، و خواندن متن کامل صفحات (با رمزگشایی خودکار).

> ابزار غیررسمی است و از API عمومی وب‌سایت noorlib.ir استفاده می‌کند.

> **سازگاری:** با هر دو نسل کتابخانه `mcp` کار می‌کند — نسخه 1.x (`FastMCP`) و 2.x (`MCPServer`).

## ابزارها (Tools)

| ابزار | کار |
|---|---|
| `noorlib_search` | جستجوی کلی در کل کتابخانه (عنوان/مؤلف/اسنیپت) |
| `noorlib_book_info` | متادیتای کتاب (عنوان، پدیدآور، جلد، رایگان؟) |
| `noorlib_book_toc` | فهرست مطالب درختی + `zone` (بازه صفحه هر بخش) |
| `noorlib_book_page` | متن کامل یک صفحه (رمزگشایی + تبدیل به متن ساده + تصویر اسکن) |
| `noorlib_search_in_book` | جستجو داخل یک کتاب → اسنیپت + شماره صفحه/بخش |
| `noorlib_find_pages` | ایندکس سریع: صفحه‌های حاوی کلمات |

## نصب

```bash
# در پروژه MCP خودتان (پوشه‌ای مثل MCP-noorlib)
cd ~/MCP-noorlib
python3 -m venv .venv
.venv/bin/pip install noorlib-mcp-2.0.0-py3-none-any.whl
# یا از سورس:
.venv/bin/pip install .
```

## ثبت در Cursor / Claude Desktop

`~/.cursor/mcp.json` (یا `.cursor/mcp.json` پروژه):

```json
{
  "mcpServers": {
    "noor": {
      "command": "/home/ALIZARE84/MCP-noorlib/.venv/bin/noor-mcp"
    }
  }
}
```

> **دو نام، یک برنامه:** هم `noor-mcp` و هم `noorlib-mcp` نصب می‌شوند (هر دو به یک entry point وصل‌اند) — هر کدام را در mcp.json گذاشتید کار می‌کند. اگر قبلاً خطای `namespace "noor" not found` می‌گرفتید، دلیلش همین نام‌گذاری بود؛ الان هر دو نام موجودند.

بعد از تغییر mcp.json، **Cursor را کامل ببندید و دوباره باز کنید** (نه فقط Reload) تا سرور MCP بالا بیاید.

## متغیرهای محیطی

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `NOORLIB_MCP_AUTH` | خالی | توکن لاگین (`Bearer eyJ...`) برای خواندن صفحات غیر رایگان (شارژ اعتبار) |
| `NOORLIB_MCP_USE_PROXY` | `0` | `1` = استفاده از http_proxy/https_proxy سیستم |
| `NOORLIB_MCP_BASE_URL` | `https://noorlib.ir` | تغییر baseURL |
| `NOORLIB_MCP_THROTTLE` | `1.2` | فاصله بین درخواست‌ها (ثانیه) |
| `NOORLIB_MCP_TIMEOUT` | `30` | تایم‌اوت هر درخواست |
| `NOORLIB_MCP_RETRIES` | `3` | تلاش مجدد روی 429/5xx |
| `NOORLIB_MCP_LOG` | `INFO` | `DEBUG` برای لاگ کامل |

### سه مشکل تست میدانی نسخه قبل و رفع آن‌ها در 2.0.0

1. **`namespace "noor" not found`** — فایل mcp.json به `noor-mcp` اشاره داشت ولی فقط `noorlib-mcp` نصب می‌شد. الان **هر دو نام** نصب می‌شوند. (در mcp.json مسیر کامل `.venv/bin/...` را بدهید و Cursor را ری‌استارت کنید.)
2. **خطای TLS خالی از طریق پروکسی** (`SSL_ERROR_SYSCALL` / `UNEXPECTED_EOF_WHILE_READING` روی `127.0.0.1:10808`) — کلاینت جدید **پیش‌فرض پروکسی سیستم را نادیده می‌گیرد** (`trust_env=False`) و مستقیم وصل می‌شود (گواهی noorlib.ir معتبر است). اگر به پروکسی نیاز دارید `NOORLIB_MCP_USE_PROXY=1` بگذارید. متن خطاها هم الان **کامل** گزارش می‌شود (نوع + پیام استثنا).
3. **صفحه خالی با پیام شارژ** («اعتبار کافی جهت کسر شارژ مطالعه صفحه وجود ندارد») — این محدودیت سمت سرور است: خواندن متن کامل برخی صفحه‌ها برای کاربر ناشناس/بدون اعتبار مجاز نیست. راهکارها:
   - **اسنیپت رایگان است:** از `noorlib_search_in_book` استفاده کنید (متن هایلایت‌شده + شماره صفحه را می‌دهد).
   - **لاگین کنید:** در مرورگر وارد noorlib.ir شوید، از DevTools → Network یک درخواست api را باز کنید، مقدار هدر `Authorization` را کپی کنید و در `NOORLIB_MCP_AUTH` بگذارید (اگر `Bearer` نداشت خودش اضافه می‌شود). حساب‌های دارای شارژ متن کامل را می‌خوانند.
   - خروجی ابزار پیام `validation` سرور را عیناً برمی‌گرداند تا علت شفاف باشد.

### نکته مهم: `sectionNumber`

شماره صفحه **داخل هر بخش (section)** شمرده می‌شود نه داخل کل کتاب. مثلاً کتاب «تمهید القواعد» (id=1327): صفحه ۶۹ در `sectionNumber=2` است؛ اگر با `sectionNumber=1` بگیرید صفحه‌ی دیگری می‌گیرید. راه درست: از `noorlib_book_toc` نگاه کنید و `sectionNumber` را از `zone` گره مورد نظر بردارید (`{volumeNumber, sectionNumber, startPage, endPage}`).

### صفحه‌های تصویری (Scan)

برخی صفحه‌ها متن تایپ‌شده ندارند و فقط تصویر اسکن دارند؛ ابزار `noorlib_book_page` در این حالت فیلد `images` را با **URL عمومی** تصویر برمی‌گرداند (مستقیم در مرورگر باز می‌شود).

### رفتار نوسانی سهمیه رایگان

سرور noorlib برای کاربر ناشناس سهمیه مطالعه رایگان دارد و گاهی بین پیام «محتوا در دسترس» و «اعتبار کافی جهت کسر شارژ...» نوسان می‌کند. ابزار صفحه یک **تلاش مجدد خودکار** انجام می‌دهد و پیام `validation` سرور را عیناً برمی‌گرداند تا علت شفاف باشد.

## رمزگشایی صفحه‌ها (جعبه سیاه باز شد)

```
base64 (urlsafe) → UTF-8 → جابه‌جایی کاراکترهای مجاور → منهای شماره صفحه از کد هر کاراکتر
```

نکته فنی: جابه‌جایی روی **کاراکتر**‌ها است نه بایت‌ها — برای شماره صفحه‌های بزرگ (≥ ۵۹) کاراکترهای چندبایتی UTF-8 در می‌آیند و جابه‌جایی بایتی متن را خراب می‌کرد. نسخه 2.0.0 درست کار می‌کند.

